# MOBILE_DESKTOP_REQUIREMENTS — NexArtWO

## Required devices

- Desktop
- Tablet
- Phone

## Mobile must support

- Field data entry
- Taking photos when browser/device supports camera input
- Uploading receipt images
- Uploading invoices
- Uploading project before/during/after photos
- Touch-friendly modals
- Responsive forms

## Rule

A feature used in the field must not be desktop-only.
