# TOOLING_STRATEGY — NexArtWO

## Suggested usage

### VS Code / Copilot

Use for small controlled edits.

### Claude Code

Use for multi-file reasoning and bug diagnosis.

### Codex

Use for isolated tasks with strict instructions.

### Cursor / Antigravity

Use only with `.cursorrules`, project memory and file boundaries.

## Tool rule

The tool must follow the repo rules. If a tool ignores them, do not use it for risky tasks.
