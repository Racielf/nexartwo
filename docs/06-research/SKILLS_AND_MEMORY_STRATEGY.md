# SKILLS_AND_MEMORY_STRATEGY — NexArtWO

## Memory

Use memory for state that changes:

- current phase
- current task
- known bugs
- decisions
- last changes
- next actions

## Skills

Use skills for repeatable workflows:

- QA audit
- bug repair
- financial formula review
- Supabase script review
- regression testing

## Rule

Memory = where the project stands.  
Skill = how to perform a repeated process.
