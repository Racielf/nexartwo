# DEFINITION_OF_DONE — NexArtWO

A task is done only when:

- Scope stayed within `CURRENT_TASK.md`.
- No protected files were touched without approval.
- The app still loads.
- The changed flow works.
- One adjacent flow still works.
- Console has no new critical errors.
- Mobile impact checked if UI changed.
- Financial calculations checked if financial logic changed.
- Memory updated.
- Remaining risks documented.
