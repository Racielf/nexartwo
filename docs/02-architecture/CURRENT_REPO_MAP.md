## Build

`npm run build` runs `scripts/build-vercel.js`, regenerates `dist/`, copies runtime assets, and creates build environment output. Never edit `dist/` directly.

## Ownership Rule

Use `AGENTS.md` for the reading route and `docs/02-architecture/FILE_OWNERSHIP_MAP.md` plus source call sites for file ownership. If a map conflicts with current code, stop and document the verified contract before editing.
