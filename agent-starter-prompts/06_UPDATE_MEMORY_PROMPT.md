# Prompt 6 — Actualizar memoria después de cambios

Usa esto después de una tarea completada.

```txt
TAREA:
Actualizar la memoria viva del proyecto después de la tarea realizada.

ARCHIVOS PERMITIDOS PARA MODIFICAR:
- memory/PROJECT_STATE.md
- memory/CHANGELOG.md
- memory/KNOWN_ISSUES.md
- memory/BUG_FIX_LOG.md
- memory/NEXT_ACTIONS.md

ARCHIVOS PROHIBIDOS:
- index.html
- projects.html
- js/
- css/
- sql/
- supabase/

INSTRUCCIONES:
Actualiza la memoria con:

1. qué se hizo
2. qué archivos cambiaron
3. qué pruebas se hicieron
4. qué quedó pendiente
5. riesgos restantes
6. próxima tarea segura recomendada

No modifiques código.
Antes de cambiar los archivos, resume qué vas a escribir y espera mi GO.
```
