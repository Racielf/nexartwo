# Cuando el agente se confunde

Si el agente empieza a desviarse, copia y pega esto:

```txt
Stop.

No sigas codificando.

Vuelve a leer:
- AGENTS.md
- memory/CURRENT_TASK.md
- docs/00-governance/STOP_CONDITIONS.md

Resume:
1. cuál era la tarea original
2. qué archivos estaban permitidos
3. qué archivos tocaste o querías tocar
4. si te saliste del scope
5. cómo volver al cambio mínimo seguro

No hagas más cambios hasta que yo diga GO.
```
