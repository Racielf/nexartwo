# Orden de uso recomendado

## Paso 1 — Instalar documentación

Primero instala:

```txt
NexArtWO_Project_Control_Pack_v2.zip
```

en la raíz del repo.

## Paso 2 — Abrir agente

Usa:

```txt
01_START_NEW_SESSION_PROMPT.md
```

## Paso 3 — Primera tarea segura

Usa:

```txt
02_FIRST_SAFE_TASK_FUNCTION_INDEX.md
```

Esta tarea es solo lectura + documentación. No toca código.

## Paso 4 — Si encuentras bugs

Usa:

```txt
04_SAFE_BUG_FIX_PROMPT.md
```

## Paso 5 — Si vas a pedir una mejora

Usa:

```txt
05_SAFE_CODE_TASK_PROMPT.md
```

## Paso 6 — Al terminar sesión

Usa:

```txt
06_UPDATE_MEMORY_PROMPT.md
```

y luego:

```txt
07_AGENT_HANDOFF_PROMPT.md
```
